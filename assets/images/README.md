# Veyra Website Image Assets

This directory is reserved for the approved **public-facing** Veyra visual library.

## Structure

```text
assets/images/
├── brand/
│   ├── favicon.png
│   ├── veyra-emblem.webp
│   └── veyra-home-hero.webp
├── maps/
│   └── veyra-current-world-map.webp
├── regions/
│   ├── aldara.webp
│   ├── caelora.webp
│   └── tsukara.webp
└── ui/
    ├── dividers/
    ├── icons/
    └── ornaments/
```

## Signature artwork

- `brand/veyra-home-hero.webp` — homepage hero panorama.
- `brand/veyra-emblem.webp` — approved Veyra emblem/site mark.
- `maps/veyra-current-world-map.webp` — master current-world visual reference for the public site.
- `regions/aldara.webp` — Aldara regional key art.
- `regions/caelora.webp` — Caelora regional key art.
- `regions/tsukara.webp` — Tsukara regional key art.

- `divider-sundering-compass.webp` — history, Sundering, Shattered Isles, signature transitions. Use rarely.

- `divider-tide-compass-rose.webp` — Tsukara, sea travel, Dawning Coast, Shattered Isles.

## Ornament usage

Large emblems and frame corners are **signature assets**, not ordinary borders. Use them on maps, hero panels, and a small number of important callouts so they remain special.

The four frame corners are designed as a set, with mountain motifs above and wave motifs below.

## Public-lore boundary

Visual assets must not be used to imply unpublished or GM-only facts. In particular, do not create an accurate Elderwood interior map, common personal firearms, hidden cosmology, secret divine truths, or other details absent from the Player/Public Source.
