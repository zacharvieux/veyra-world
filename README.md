# Veyra World

Public-facing website for **Veyra**, a heroic fantasy world shaped by the Sundering, lost history, dangerous frontiers, old faiths, changing technology, and difficult choices.

## Publishing boundary

This repository is **public-only**. Website lore must come from the approved `Veyra_Player_Public_Source.md` and the `Veyra_Website_Content_Manifest.md` maintained outside this repository.

Do **not** add GM-only material, hidden cosmology, secret faction truths, protected mysteries, unapproved settlements, exact demographics, or other material intentionally omitted from the public source.

## Branches

- `main` — stable/public release branch
- `develop` — active website development
